Project

Secure Multi-User USB Drive

A multi-bank USB drive secured by fingerprint and password.

  • KiCAD
  • C/C++
  • STM32

This project is a USB device that makes it possible for four separate users to utilize the same device to access separate data.

This project was created as a part of the ECE 47700 senior design course at Purdue University alongside Brandon Liu, Stanley So, and Joshua Wai.

The team created a device that takes in input of a fingerprint or password to allow users access to their data on a USB drive.

In this device, the individual components were selected and prototyped, the circuitry was modeled and the PCB was designed in KiCAD, the components were soldered onto the board, the microcontroller was programmed with the firmware for the product, and the casing was modeled and 3D printed for the device.

The fully assembled PCB:

The drive is controlled by a STM32H7 microcontroller, utilizing an LCD screen for a HUD, a keypad to receive password input, a fingerprint sensor to receive fingerprint data, and a SPI NAND flash to store data.
